Install Ketoy How it works
CheckoutScreen.kt @KetoyEntryPoint 
@KetoyEntryPoint @Composable
fun CheckoutScreen() {
    val vm    = ketoyViewModel<CheckoutViewModel>()
    val state by vm.state.collectAsState()

    Scaffold(topBar = { TopAppBar(title = { Text("Checkout") }) }) { p ->
        LazyColumn(modifier = Modifier.padding(p)) {
            items(state.cartItems) { item ->
                ProductCard(name = item.name, price = item.price)
            }
        }
        Button(onClick = { vm.dispatch("place_order") }) {
            Text("Place Order — $" + state.total)
        }
    }
}

Your existing Kotlin and Compose code. Shipped over the air.

The two-layer parameter system

Static where it can be. Real JVM objects where it must be.

Compose parameters split into two categories. Primitives, colors, and modifiers are encoded statically — zero allocation. Complex types like TextStyle and KeyboardOptions are constructed at runtime via CONSTRUCT_JVM.

Layer 1

KBCValue — static constants

35 variants covering every Compose primitive. Decoded with a direct when() at render time.

Color.Red → ColorARGB (5 B)
FontWeight.Bold → FontWeightInt(3 B)
16.sp → Sp (5 B)
Modifier.padding() → ModifierRef (3 B)
<default> → Default (0 B)
Layer 2

CONSTRUCT_JVM — real objects

17 built-in constructor adapters for complex types: TextStyle, KeyboardOptions, RoundedCornerShape, Shadow, AnnotatedString, and more.

CONSTRUCT_JVM r5 TEXT_STYLE
  param[0]: Sp(16f) // fontSize
  param[3]: FontWeightInt(700) // fontWeight
COMPOSABLE_CALL OUTLINED_TEXT_FIELD
  param[5]: Register(5) // real TextStyle

Security model

The load-bearing wall of the architecture.

Security in Ketoy isn't a feature flag — it's the boundary between your runtime and everything else.

Ed25519 signing

Every bundle, every load. 64-byte signature verified before any parsing. The public key ships in your APK; the private key stays on your signing server.

Compile-time sandbox

The K2 plugin rejects direct Android API access, reflection, file I/O, and GlobalScope. Forbidden calls are build errors — not runtime exceptions.

Play Store-compliant

No pre-built DEX downloaded. The on-device JIT generates DEX from KBC locally — the same thing ART does with bytecode. Explicitly permitted by policy.

Quick start

Three blocks. One Gradle task.

Add the plugin, write your screen, run ketoyBundle. Upload the .ktx file to your CDN.

build.gradle.kts 
plugins {
  id("dev.ketoy.compiler") version "0.3.3-alpha"
}

dependencies {
  implementation(platform("dev.ketoy.vm:ketoy-bom:0.3.3-alpha"))
  implementation("dev.ketoy.vm:ketoy-runtime")
  implementation("dev.ketoy.vm:ketoy-hilt")
  implementation("dev.ketoy.vm:ketoy-adapters-material3")
  ksp("dev.ketoy.vm:ketoy-ksp-processor")
}
HomeScreen.kt 
@KetoyEntryPoint
@Composable
fun HomeScreen() {
  val vm    = ketoyViewModel<HomeViewModel>()
  val state by vm.state.collectAsState()

  Column(modifier = Modifier.fillMaxSize().padding(16.dp)) {
    Text("Welcome, " + state["name"])
    Button(onClick = { vm.dispatch("get_started") }) {
      Text("Get Started")
    }
  }
}
terminal ~60s rollout
